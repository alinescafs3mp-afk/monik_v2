# Monik v2

Самостоятельный монитор хостов и локальных HTTP/HTTPS-сервисов: один сервер на Go со встроенным Vue 3 UI и SQLite, нативные агенты Linux и Windows.

Адрес по умолчанию: `https://46.120.103.61:8777`. Сохранённый адрес всегда важнее значения по умолчанию.

**До полного v3-приёмки остаются блокеры среды, а не пустые кнопки.** Подписанное обновление worker/service-host, безопасный ребинд, ротация API-ключа, перекрытие CA и пробный HTTP-check реализованы и покрыты тестами. Не подтверждены нативная служба Windows до входа пользователя, суточный прогон и живой сервер владельца. Подробности: `IMPLEMENTATION_STATUS.md`, `ACCEPTANCE_LEDGER.md`. Работающая установка этим коммитом не обновляется.

## Сборка

Нужны Go из `go.mod` (сейчас 1.27.0) и Node 22. Собранная веб-морда больше не хранится в Git: `make all` сначала собирает UI. При ручной сборке сервера сначала выполните `make ui`. Без неё сервер отдаст понятную ошибку 503 вместо устаревшего интерфейса.

```bash
make ui && make linux && make windows
```

Агент для раздачи:

- Linux: `dist/linux-amd64/monik-agent` и `dist/linux-amd64/monik-service-host`
- Windows: `dist/windows-amd64/monik-agent.exe` и `dist/windows-amd64/monik-service-host.exe`

## Сервер

```bash
./dist/linux-amd64/monik-server setup --non-interactive \
  --listen 0.0.0.0:8777 \
  --advertised-url https://<LAN-IP>:8777
./dist/linux-amd64/monik-server run --data-dir ~/.local/share/monik-server
```

Пароль администратора: `$data-dir/admin-bootstrap.txt` (0600). UI — HTTPS, порт 8777. Первичная веб-настройка только с loopback.

## Агент

В UI: **Добавить машину** → код на 10 минут → `enrollment.yaml`.

```bash
./monik-agent setup --profile enrollment.yaml
# неуправляемый режим:
./monik-agent run --config ~/.local/share/monik-agent/agent.json
# управляемый:
sudo ./monik-agent service install --config /var/lib/monik-agent/agent.json
```

TLS агента проверяет CA контроллера. Не отключайте проверку сертификата.

## Обновления, ребинд, ключи и проверки

Импорт комплекта проверяет metadata TUF против независимо зачисленного root (`enroll_root` только на первый доверенный репозиторий). Раскатка и перезапуск требуют управляемой установки (`monik-agent service install`). Неподготовленный агент не переключается на неизвестный адрес при `rebind.activate`. Ключи подписи храните отдельно от работающего контроллера.

Ротация API-ключа — перекрывающийся обмен: агент сначала пишет следующий секрет, регистрирует verifier по старому каналу, затем доказывает новый токен. `trust.stage` / `trust.retire` меняют набор CA на агенте; последний корень снять нельзя. «Пробный запрос» выполняется на агенте, не с контроллера.

Windows-сборки проверены компиляцией. Запуск службы до входа пользователя, перезагрузка и восстановление после неудачного обновления на Windows **не** считаются принятыми, пока нет нативного прогона.

## Что не входит

Telegram, удалённая перезагрузка хоста, произвольные команды, установка посторонних пакетов, HA, маркетплейс плагинов.
