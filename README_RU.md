# Monik

Самостоятельная мониторная для своих машин: один сервер с Vue-интерфейсом и SQLite, агенты для сбора метрик и проверки локальных веб-сервисов.

**Текущие исходники: Audit 6, до релиза.** [Аудит](docs/AUDIT_REVIEW_6_2026-09-14.md), [инструкция по новым функциям](docs/V6_OPERATIONS_RU.md), [реальное состояние](IMPLEMENTATION_STATUS.md), [проверки](ACCEPTANCE_LEDGER.md), [оставшиеся работы](docs/RELEASE_COMPLETION_PLAN.md).

В обзоре остаются только отмеченные машины с CPU/RAM/DISK/ping и краткими состояниями сервисов. Сервисы сгруппированы по машинам; запрос настраивается в явном редакторе. Графики подписаны, история фиксируется выбранным временем, переименование не сбрасывается телеметрией.

В Audit 6 добавлены работающие общие пороги CPU/RAM/DISK, плановое обслуживание с сохранением измерений, фильтр непрочитанных инцидентов и повторное внимание при критическом ухудшении, подтверждение чувствительных действий и смена пароля владельца. Диагностика показывает фактические границы данных и отставание очистки, не выдуманную полноту истории.

## Важно при обновлении

Приём неизвестных агентов по автоматическому профилю теперь по умолчанию закрыт. В «Добавить машину» откройте окно на выбранный период, затем запустите агента и подтвердите отпечаток. Работающие агенты, уже ожидающие кандидаты и одноразовые коды не отключаются при закрытии окна. Существующие машины заново регистрировать не нужно.

Адрес по умолчанию `https://46.120.103.61:8777` используется только для начальной настройки. Сохранённый реальный адрес важнее. Исходный коммит сам по себе не обновляет работающую установку.

## Сборка и внедрение

Сначала соберите интерфейс (`npm ci`, тесты, TypeScript, `npm run build` внутри `web`), затем сервер и агенты (`go test -race`, `go vet`, `make dist`). Точный порядок есть в английском README и передаточной инструкции пакета. Генерируемые файлы интерфейса не хранятся в Git.

Перед внедрением сохраните полное защищённое состояние контроллера и проверьте новые индексы/схему на копии базы. Сначала обновляются сервер и UI, затем совместимые агенты. При смене пароля завершаются браузерные сессии, но ключи агентов остаются прежними.

## Что ещё не готово

Независимое восстановление при обновлении служебного компонента агента, полная нативная установка с правильными учётными записями/правами Windows и Linux, неизменяемые релизы с управляемыми партиями, полноценный restore со сверкой старых команд, длительные агрегаты и испытания парка остаются обязательными работами. Это не только ограничения тестовой среды: часть функций ещё нужно реализовать.

Новые правила пока общие и только процентные для трёх метрик. Обслуживание не отключает реальные измерения и не делает красный сервис зелёным. Текущая браузерная приёмка v6 в среде аудитора заблокирована до входа; успешный старый браузерный тест не подменяет её. Нативные Windows-службы и отключение питания не подтверждаются кросс-компиляцией.

Telegram, удалённая консоль, перезагрузка хостов и управление чужими приложениями не добавлены.
