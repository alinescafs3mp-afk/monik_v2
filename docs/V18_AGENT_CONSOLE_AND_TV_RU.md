# V18: консоль через агент и управление шириной с пульта

## Что теперь есть

В окне консоли два явных режима: **Через агент** и **Прямое SSH**. Первый выбран по умолчанию. Это настоящий Linux-терминал, а не выполнение одной команды раз в пять секунд. Ввод, вывод, Ctrl+C, текущий каталог и изменение размеров идут отдельным потоком. SSH остаётся независимым вариантом с собственными настройками и реквизитами.

Агент сам соединяется с уже известным ему контроллером по WSS на том же HTTPS-порту. Новый входящий порт на удалённой машине и sshd для этого пути не требуются. Закрытый NAT не препятствует исходящему соединению сам по себе, но firewall/proxy должны пропускать WSS. Если обычные метрики приходят, это ещё не доказывает доступность постоянного канала.

## Права: важное ограничение

Консоль через агент сейчас работает под отдельной непривилегированной учёткой **monik-console**. Это не root, не учётка сборщика monik и не твой SSH-admin. У неё свой домашний каталог, нет доступа к защищённым ключам мониторинга, дополнительных групп и права повыситься через sudo/setuid. Предусмотрены ограничения systemd на файлы, процессы и память.

Можно запускать доступные этому пользователю программы, смотреть общедоступное состояние и работать в его каталоге. Это НЕ строго read-only терминал и НЕ полноценный административный вход. Для защищённых журналов, установки пакетов, редактирования системных файлов и других администраторских задач остаётся **Прямое SSH** с проверенной учётной записью. Устанавливать весь агент от root ради этого не нужно.

Компрометация действующего owner-входа или контроллера остаётся серьёзным риском: она даёт доступ к разрешённым терминалам в пределах этих прав. Никакой собственный аудит не делает продукт неуязвимым. Не оставляйте owner-вход на общедоступном телевизоре.

## Новая машина: по-прежнему один файл

После интеграции и приёмки Гроком:

1. На странице «Добавить машину» осознанно отметить **«Разрешить консоль через агент»**. По умолчанию галочка снята.
2. Скачать новый персонализированный Linux-агент и запустить его обычным локальным `sudo`.
3. Установщик ставит согласованную пару и отдельно разрешённый локальный компонент. Он не добавляет root к сетевому агенту.
4. Дождаться мониторинга, открыть «Консоль» нужной машины и проверить статус канала. Нажать «Подключиться». При необходимости подтвердить текущий пароль владельца Monik.

Не нужны SSH-пароль, SSH-адрес или отдельный fingerprint для агентского режима. Доверие берётся из существующей регистрации. Одноразовый установочный файл всё ещё конфиденциален до расходования кода; не публикуйте его.

Подтверждение готовности мониторинга и применения локальной политики не равняется успешному открытию терминала. Канал показывается отдельно в интерфейсе.

## Существующая машина

Сначала Гроку нужно безопасно обновить **и рабочий агент, и защищённый service-host** из V18, сохранив конфигурацию, ключи, URL, очередь и идентичность. Обычная удалённая замена только рабочего агента не обновит локальный компонент. Самообновление service-host пока не реализовано и остаётся заблокированным.

После согласованного локального обновления стандартной Linux/systemd-установки:

```sh
sudo /usr/lib/monik/monik-service-host console-enable
```

Это одноразовое местное разрешение. Веб-панель не может сама выдать его себе. Действующих агентов не нужно перерегистрировать.

Проверки пилота:

```sh
systemctl status monik-agent.service monik-console.socket
systemctl list-units 'monik-console@*.service'
journalctl -u monik-console.socket --no-pager -n 40
```

В процессе открытой консоли должны быть отдельные процессы `monik-console`, а не root. На тестовой VM Грок проверяет фактические UID, группы, отсутствие capabilities, `NoNewPrivs: 1`, запрет чтения ключей, файловые ограничения, остановку всей группы и работу после перезагрузки. Простое наличие файлов unit этого не доказывает.

Выключить разрешение локально:

```sh
sudo /usr/lib/monik/monik-service-host console-disable
```

Это закрывает сокет и связанные сеансы, не удаляет машину, историю или ключи. Если systemd/локальная политика неисправны, терминал не должен запускаться обходным путём.

Поддерживаются стандартные Linux-пути. Windows/ConPTY и произвольные пользовательские аккаунты через агент в этой версии не реализованы. Для них остаётся SSH.

## Работа и разрыв связи

Билет подключения живёт 30 секунд, одноразовый и относится только к выбранной машине/каналу/входу. Терминал ограничен одним часом, десятью минутами без ввода и 16 МиБ вывода. До четырёх активных агентских сеансов на контроллере, один на машину. Это ограничения, а не подтверждённая производительность большого парка.

Ввод не сохраняется в job/spool и не повторяется после перезагрузки. При разрыве соединения сеанс закрывается; сам канал может восстановиться, но новая оболочка автоматически не открывается. При отзыве входа, роли владельца, ключа агента или локального разрешения соединение отзывается. Обрыв сети определяется по таймауту, не мгновенно.

Уже выполненные изменения не отменяются закрытием вкладки. Для полного завершения отделённых процессов требуется проверенная политика systemd cgroup. Отдельный обычный SSH сохраняет свои семантику и права.

В журналы Monik пишутся факты подключения/закрытия, не содержимое терминала. Система не даёт гарантии удаления истории, которую самостоятельно сохраняет запущенная программа или ОС.

## SSH остаётся

Во вкладке «Прямое SSH» можно настроить IP целевой машины, SSH-порт, логин и независимо проверенный ключ хоста. Адрес контроллера нельзя автоматически считать адресом SSH этой машины. Сохранение конфигурации не является доказательством подключения. Смена цели отзывает старые билеты и сеанс. Старые вкладки обновите после интеграции V18.

## Пульт телевизора: без долгого зажатия

Долгое зажатие у некоторых ТВ-браузеров включает собственный курсор перемещения и не даёт странице обычных событий drag. В V18 не требуется преодолевать этот режим.

В телевизионном обзоре нажмите **«Ширина колонок · пульт»** обычным коротким нажатием OK.

- **Влево / вправо**: двигать выбранную границу на 8 CSS-пикселей.
- **Вверх / вниз**: выбрать другую границу.
- **OK**: сохранить настройку.
- **Назад / Escape**: отменить незавершённое изменение.

Показаны название выбранной колонки и её ширина. Есть обычные кнопки **«− Уже»**, **«+ Шире»**, **«Применить»**, **«Отмена»** для пульта с виртуальным курсором, который передаёт только клики. Они не зависят от долгого удержания или Pointer Capture.

Пока режим активен, автолистание и перемещение строк не мешают настройке; значения метрик продолжают обновляться. Колонки сохраняются на устройстве отдельно для ТВ и обычного вида. На узком экране ручки отключаются вместе с переходом к переносимой раскладке. Если браузер перехватывает клавишу Назад раньше страницы, используйте видимую кнопку «Отмена».

Кнопка «Консоль» в ТВ находится в отдельном видимом блоке действий, для которого зарезервирована ширина. Физический пульт и Яндекс на конкретном телевизоре аудитор не проверял; это отдельная приёмка после раскатки.
