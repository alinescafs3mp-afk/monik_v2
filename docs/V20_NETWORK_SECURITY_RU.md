# V20: внедрение и сетевые границы

## Что обновлять

Обновить контроллер и встроенный интерфейс из одной сборки. Действующие агенты и service-host ради V20 заменять или перерегистрировать не нужно. Для новых скачиваний пересобрать согласованные установочные шаблоны, как требует существующая проверка build-id. Не менять права служб, выбранные адреса, CA, идентичность, конфигурации и журналы.

После обновления перезагрузить старые браузерные вкладки. Вход и сохранённые сессии специально не сбрасываются. Общий ТВ-профиль, выбор машин/сервисов, имена, паузы и операции сохраняются.

## Что заметно пользователю

* Ручное создание кода регистрации теперь требует недавнего подтверждения паролем владельца, как персонализированный установщик. Настройки геометрии ТВ не требуют такого подтверждения.
* Читатель viewer больше не получает действующие коды регистрации и чувствительные параметры через журнал операций. Владелец видит исходный результат; запись в базе не уничтожается.
* Отзыв ключей не объявляется успешным при ошибке сохранения. Если операция не подтверждена, перечитать результат по её исходному идентификатору и проверить фактическое состояние, а не предполагать отзыв по одному нажатию.
* Сбой чтения базы не выглядит пустым списком резервных копий/секретов или отсутствующей исходной операцией.
* При насыщении проверки пароля будет 503 с Retry-After; при превышении лимита потоков событий 429. Закройте лишние вкладки. Парольные проверки ограничены двумя одновременно, SSE восемью на сессию и 128 на контроллер.
* При узком окне ТВ блоки получают явный перенос, пока браузер пересчитывает ширины. Это не синхронизация паролей и не сброс общего профиля.

## HTTP-клиенты и обратный прокси

Родной интерфейс уже отправляет JSON правильно. Собственный клиент для /api/v1/login или /api/v1/setup должен передавать `Content-Type: application/json`. `text/plain` и простая HTML-форма для этих действий больше не принимаются.

Браузерные изменения требуют совпадения Origin с фактическими схемой, именем и портом запроса. Чужой Origin, в том числе `null`, отклоняется. CSRF, cookie, роль владельца и отдельная авторизация консоли остаются обязательными.

Заголовки X-Forwarded-For/Host/Proto не дают доверия сами по себе. Не исправлять отказ Origin отключением проверки TLS/CSRF или разрешением всех источников. При нестандартном прокси проверить реальную схему TLS и Host на одном пилоте. В V20 не добавлен режим автоматического доверия TLS-терминатору. Нативные агенты с bearer-ключом используют свой API, а не браузерный вход.

Рабочий внешний адрес контроллера остаётся https://46.150.103.61:8777. Сохранённые LAN-маршруты существующих агентов не переписывать. В этом аудите внешний адрес не сканировался и его доступность не проверялась.

## Приёмка на локальной VM

1. Сохранить согласованную защищённую копию состояния и независимый доступ. Не считать встроенный экспорт измерений полным restore.
2. Применить патч только к подходящей базе, собрать и выполнить `scripts/verify-audit20.sh --with-browser` в отдельном тестовом checkout.
3. Отдельно проверить общий ТВ-профиль на компьютере/телевизоре, включая возврат сети и ширину 390px, а также отсутствие скачков прокрутки и потери черновика.
4. На тестовых учётках проверить: viewer видит журнал без кодов; просроченная недавняя авторизация требует пароль для нового кода; выход закрывает поток событий и консоль; новый вход восстанавливает обычную работу.
5. На отдельном тестовом агенте проверить отзыв ключа и отказ следующего отчёта. Не отзывать ключи рабочих машин ради проверки и не удалять их регистрацию.
6. Проверить метрики, выбранные сервисы, историю, операции, общую ТВ-геометрию и оба разрешённых способа консоли. Не запускать боевую раскатку обновлений только ради этого UI/server патча.

## Ограничения

Успешный аудит исходников не является гарантией недоступности VM для злоумышленника. Компрометация owner/контроллера всё ещё даёт возможности, которые вы ему разрешили. Агентский терминал остаётся отдельным локально разрешённым непривилегированным режимом, не root.

Здесь не проверялись внешний периметр, актуальные CVE всех зависимостей, настоящая загрузка systemd/SCM, физический телевизор, весь парк или сутки работы. Эти гейты не закрывать ссылкой на число тестов.
