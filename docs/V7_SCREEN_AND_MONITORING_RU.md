# Monik v7: телевизор, выбор сервисов и сохранение входа

Это руководство к подготовленному исходному коду. Оно не подтверждает, что ваша установленная версия уже обновилась.

## Две галочки у каждого сервиса

| Проверять | В обзоре | Результат |
|---|---|---|
| Да | Да | Периодические запросы и показ в строке выбранной машины |
| Да | Нет | Запросы и история продолжаются; сервис не занимает место в обзоре |
| Нет | Да | В обзоре видна остановленная проверка, а не старое зелёное здоровье |
| Нет | Нет | Запросы выключены после подтверждения агентом, в обзоре сервиса нет |

Машина сама должна быть отмечена «Показывать в обзоре». Если сервис отдельно скрыт, скрытие нужно снять: одного закрепления недостаточно. Ошибки проверяемых сервисов вне видимого списка не исчезают из инцидентов и счётчика проблем машины.

Галочки доступны в общем сгруппированном списке сервисов и на странице конкретной машины. «В обзоре» сохраняется на сервере сразу. «Проверять» создаёт новую конфигурацию, и интерфейс отдельно сообщает об ожидании агента. Уже начатый запрос может дойти до своего таймаута. Офлайн-машина выполнит изменение только после получения.

В разделе сервисов машины есть массовое выключение проверок и включение неигнорируемых сервисов. CPU, RAM, DISK, ping и связь с контроллером при этом продолжаются. Индивидуальное включение игнорируемого сервиса явно снимает игнорирование; массовое включение его сохраняет.

## Новые найденные сервисы

По умолчанию агент ограниченно распознаёт новый порт, а сервер создаёт выключенную проверку. Сначала выберите нужные сервисы и при необходимости настройте их запросы. Старые работающие проверки от одного обновления не выключатся: для них используйте массовую кнопку на нужной машине.

Опция «Автоматически проверять новые найденные сервисы» предназначена для машин, где вы сознательно разрешаете этот режим. Для неё требуется новый агент с возможностью `selective_monitor_v1`. Она также разрешает дополнительные ограниченные попытки подбора health-маршрута. Готовые пользовательские определения не переписываются.

Выключенный сервис после применения конфигурации не получает запросов повторного обнаружения: его порт остаётся виден в инвентаризации. Первичное определение ранее неизвестного порта всё ещё отправляет небольшие запросы. Это не полностью пассивный сканер. Ручная кнопка пробного запроса является явным разрешением выполнить одну проверку.

## Телевизор

В верхней панели выберите «Телевизор». Появятся плотности «Крупнее», «Плотно», «Максимум строк». Начните с «Плотно»; при небольшой рабочей области браузера используйте «Максимум строк». Масштаб самого Яндекса можно оставить 100%.

ТВ-режим использует всю доступную ширину, прячет боковую панель и выводит короткие строки. В строке есть машина, CPU/RAM/DISK/ping и две выбранные проверки. Для остальных видно количество и переход к подробностям. Это не обещание отобразить сотню длинных ответов в одной строке.

Количество строк на странице вычисляется по реальной рабочей области, а не по надписи 4K на телевизоре. Есть «Назад»/«Далее» и отдельная галочка автоматического листания каждые 20 секунд. Листание приостанавливается, когда вы взаимодействуете с панелью или вкладка скрыта. Плотность и режим запоминаются на устройстве; автоматическое листание включается заново явно.

Кнопка полного экрана необязательна. Если браузер её запрещает, компактный вид остаётся. Для прямого открытия можно добавить `?display=tv` к адресу обзора. Параметр не содержит пароля и не обходит вход. После ручной смены режима такой адрес больше не возвращает прежний выбор при перезагрузке.

На вашем физическом ТВ/Яндексе это ещё нужно проверить. Проверки размеров в исходниках и сценарий Chromium не равны реальному телевизионному испытанию. Отдельной навигации стрелками пульта в этой версии нет; обычные фокусируемые кнопки и ссылки сохранены.

## Телефон

Обычный режим подстраивается под узкий экран, сохраняет крупные области нажатия и переносит панели. Таблицы со множеством столбцов прокручиваются внутри своего блока. Уменьшение масштаба браузера не требуется, жест увеличения не запрещается. На телефоне не включайте максимальную ТВ-плотность для обычного управления.

## Вход

Глазик показывает уже введённый пароль без отправки формы; повторное нажатие скрывает. Галочка «Запомнить вход на 30 дней» сохраняет защищённую сессию, а не пароль в приложении. Она по умолчанию выключена. Без неё серверная сессия живёт не больше 12 часов. С ней установлен абсолютный предел 30 дней, после которого нужен новый вход.

Сам пароль можно дополнительно сохранить штатным менеджером браузера, если он это поддерживает. Сайт передаёт правильные атрибуты полей, но не может принудительно включить хранение паролей в конкретном Яндексе. Частный режим, очистка cookie или политика ТВ могут удалить сохранённый вход раньше срока.

В настройках видны активные браузерные входы и их сроки. «Выйти на остальных устройствах» требует текущий пароль и оставляет текущую сессию. «Выйти» завершает текущую; смена пароля завершает все. Агентов это не переподключает.

ТВ-раскладка не является отдельной ролью только для чтения. Запоминайте вход владельца только на своём защищённом телевизоре. Для публичного экрана нужна отдельная ограниченная авторизация, пока она не реализована.

## Что этот пакет не объявляет завершённым

Установка служб с проверенными правами на чистых Linux/Windows, независимое восстановление при обновлении служебного компонента, полный перенос/restore контроллера, партии обновлений и длительная агрегированная история остаются обязательными работами до общего релиза. Наличие TV-режима эти условия не заменяет.
